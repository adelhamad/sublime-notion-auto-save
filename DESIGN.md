# Design

The supplied Adel Dev Tools page is the visual authority. This page extends its documentation design.

- Paper: #f4f2e9; raised: #fbfaf5; quiet: #ece9dc.
- Ink: #23241f; secondary: #575950; faint: #66685f.
- Rules: #aaa99e and #d5d2c5; links: #315f98; success: #36734d.
- JetBrains Mono variable for headings, prose, controls, and code, following the reference.
- A 48px ruled header, compact anchor navigation, centered 1012px content, bordered reference sections, and square controls.
- The signature element is an interactive editor demonstration that visibly closes a note while its upload continues.
- Keep content legible on phones, preserve keyboard focus, and respect reduced motion.
